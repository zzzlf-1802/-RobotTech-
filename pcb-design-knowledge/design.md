# PCB 设计指南

> 本文档涵盖 PCB 设计全流程：原理图设计、PCB 布局布线、高速信号完整性/电源完整性/EMC、可制造性/可测试性/可装配性设计、热设计、DDR5/PCIe 布局规范。

---

## 一、原理图设计

### 1.1 设计流程

```
需求分析 → 功能框图 → 器件选型 → 原理图绘制 → ERC检查 → BOM输出
```

**设计步骤详解：**

1. **需求分析阶段**
   - 明确功能需求、接口定义、性能指标
   - 确定电源需求：电压等级、电流容量、功耗预算
   - 确定机械约束：板形尺寸、安装孔位、高度限制
   - 确定环境要求：工作温度、湿度、振动等级

2. **功能框图阶段**
   - 绘制系统级功能框图，明确各模块功能与接口
   - 划分电源域：模拟电源、数字电源、射频电源等
   - 定义信号流向与关键路径
   - 标注主要约束条件（阻抗、时序、速率等）

3. **器件选型阶段**
   - 功能满足：确保器件满足设计规格要求
   - 供应保障：优选量产型号，考虑交期与替代料
   - 成本控制：在性能允许范围内优化BOM成本
   - 封装选择：综合考虑焊接可靠性、散热、装配难度

4. **原理图绘制阶段**
   - 按功能模块分区绘制
   - 正确标注器件位号、标称值、封装
   - 添加必要的测试点与调试接口
   - 完成注释与设计说明

5. **ERC检查阶段**
   - 运行电气规则检查
   - 逐项确认并修复告警
   - 特殊设计需记录豁免原因

6. **BOM输出阶段**
   - 生成完整BOM表，包含MPN、封装、数量
   - 确认替代料与供应状态

### 1.2 AI 就绪工作流（2026 新增）

为适应 AI 辅助设计与自动化 BOM/采购流程，原理图设计应遵循以下 AI 就绪最佳实践：

**MPN 元数据标注**
- 为每一个元器件附加完整的 MPN（Manufacturer Part Number）元数据
- MPN 信息应直接关联到 LCSC/得捷/贸泽等供应商料号
- 支持一键生成可采购 BOM，无需人工补充料号信息
- 推荐使用嘉立创EDA的LCSC料号绑定功能

**结构化原理图要求**
- 清晰的模块边界：每个功能块有明确的输入输出端口
- 标准化的命名规范：信号名、电源名、器件位号遵循统一规则
- 完整的约束标注：阻抗、延迟、长度匹配等约束在原理图中显式定义
- 层次化设计：复用模块使用层次图（Hierarchical Sheet）组织

**可追溯性设计**
- 每个关键信号标注来源与去向
- 电源网络标注额定电流与电压精度要求
- 差分对网络显式标注阻抗要求
- 长度匹配约束以网络类（Net Class）形式定义

### 1.3 高速原理图结构设计

**电源域分离原则**
- 模拟电源与数字电源单点连接或通过磁珠隔离
- 高速SerDes电源使用独立LDO或DC-DC供电
- PLL/时钟电路电源添加专用滤波网络
- 不同电压域清晰划分，避免地弹噪声耦合

**差分对定义**
- 在原理图中明确标记差分对网络（如 _P/_N 后缀）
- 显式标注差分阻抗要求（如 85Ω、90Ω、100Ω）
- 差分对的共模阻抗与差模阻抗均需考虑
- AC耦合电容位置与容值在原理图中标注

**长度匹配约束**
- 同组信号（如DDR5的DQS组）标注匹配容差
- 地址/命令/控制信号标注与时钟的匹配关系
- 差分对内 skew 约束（典型 < 5mil 或 < 5ps）
- 使用网络类（Net Class）统一管理约束

**层次化设计策略**
- 高频模块（如SerDes、射频前端）独立层次图
- 电源模块单独分层，便于评审与复用
- 高速接口（DDR5、PCIe）按通道分层
- 层次图端口命名规范，便于跨层连接检查

### 1.4 调试与可测试性设计

**测试点放置**
- 所有电源轨放置测试点，便于上电测量
- 地网络放置充足测试点，提供可靠参考地
- 关键信号路径放置测试点（时钟、复位、关键使能等）
- 高速信号测试点需避免未端接 stub，使用验证过的测试结构

**串联阻尼电阻**
- 在协议允许的信号路径上串联 10-100Ω 电阻
- 用于阻尼快速信号边沿，降低EMI与过冲
- 常见应用：时钟信号、复位信号、慢速控制信号
- 注意：高速串行信号（PCIe、USB3）不得随意添加串联电阻

**调试接口**
- JTAG/SWD 调试接口预留
- I2C/SPI 等总线预留监测点
- 关键状态信号引至测试点或LED指示
- 预留串口打印接口便于固件调试

### 1.5 层次化设计与复用

**层次图设计规范**
- 顶层图：系统级连接与主要接口
- 模块层：按功能划分的子电路
- 元件层：复用度高的标准单元电路
- 命名规范：层次名_信号名，避免歧义

**设计复用策略**
- 电源电路标准化模块
- 接口电路标准化模块（USB、以太网、HDMI等）
- MCU/FPGA 最小系统模板
- 建立内部元器件库与参考设计库

## 二、PCB 布局布线

### 2.1 层叠设计

**层叠设计原则**
- 信号层与参考平面层交替排布
- 高速信号层紧邻完整参考平面
- 电源层与地层相邻，最大化去耦效果
- 对称层叠，降低翘曲风险

**常见层叠配置**

| 层数 | 层叠结构 | 适用场景 |
|-----|---------|---------|
| 2层 | Top / Bottom | 简单低速电路 |
| 4层 | Sig-Gnd-Power-Sig | 通用数字电路 |
| 6层 | Sig-Gnd-Sig-Sig-Power-Sig | 中等密度设计 |
| 8层 | Sig-Gnd-Sig-Power-Gnd-Sig-Power-Sig | 高速设计 |
| 10层 | Sig-Gnd-Sig-Gnd-Sig-Sig-Gnd-Sig-Gnd-Sig | 高密度高速设计 |

### 2.2 十层 PCB 布线规则（2026 新增）

对于 10 层及以上的高速高密度 PCB，遵循以下布线规则：

**1. 层分配（Layer Assignment）**
- 使用来自通道仿真模型的层叠结构与材料参数
- 高速信号优先布置在与完整参考平面相邻的层
- 避免高速信号在无参考平面的层上布线
- 电源分配层与地平面紧密耦合

**2. 过孔转换次数（Transition Count）**
- 最小化高速信号的层转换次数
- 不要为了缩短走线长度而牺牲完整的参考平面
- 干净的参考平面比略微缩短的走线更重要
- 关键信号尽量在同一层完成布线

**3. 过孔结构（Via Structure）**
- 使用经过验证的焊盘/反焊盘 + 返回过孔模式
- 高速过孔必须紧邻返回地过孔
- 需要时使用背钻（back-drill）消除 stub
- 或使用盲孔/埋孔（blind-via / buried-via）
- 过孔反焊盘大小需经过阻抗验证

**4. 对内 skew（Pair Skew）**
- 按时间规格施加 skew 约束，而非仅长度
- 保持 breakout 区域与调谐区域的对称性
- 差分对内长度差需在接收器端补偿
- 避免在信号路径中间突然调谐

**5. 走线间距（Trace Spacing）**
- 间距由串扰分析结果推导，而非简单的 3W 口号
- 根据实际串扰预算计算所需间距
- 同组信号间间距与不同组信号间距区分对待
- 考虑相邻层信号的垂直耦合效应

**6. 测试接入（Test Access）**
- 高速信号不得有未端接的 stub
- 使用经过验证的测试结构（如 电阻型测试点）
- 测试点对信号完整性的影响需在仿真中考虑
- 必要时使用无探针测试方案

**7. AC 耦合（AC Coupling）**
- 遵循器件或规范要求的放置位置
- 保持耦合电容两侧走线环境对称
- 电容焊盘处的阻抗不连续需补偿
- 避免在耦合电容附近换层

### 2.3 布局策略

**布局优先级排序**
1. 连接器与接口元件（确定板边位置）
2. 核心芯片（CPU、FPGA、ASIC）
3. 电源模块（DC-DC、LDO）
4. 时钟电路（晶振、时钟发生器）
5. 存储器（DDR、Flash）
6. 外围电路与无源元件

**布局基本规则**
- 按功能模块分区布局，减少跨模块连线
- 信号流向清晰，避免迂回折返
- 高噪声电路（开关电源、时钟）远离敏感电路
- 模拟电路与数字电路物理隔离
- 发热元件均匀分布，避免热点集中
- BGA、QFP 等大封装器件留出返修空间

### 2.4 布线规则

**通用布线规则**
- 电源线宽根据电流大小确定（一般 1oz 铜厚：1A/mm 线宽）
- 地线尽可能宽，降低回路阻抗
- 信号线避免直角走线，使用 45° 或圆弧
- 过孔数量合理控制，高速信号尽量少换层
- 相邻层走线方向正交，减少串扰

**差分对布线**
- 等长：对内长度差控制在规定范围内
- 等距：保持恒定间距以维持阻抗连续
- 同层：避免差分对换层
- 对称：走线环境对称，过孔数量与位置对称

**长度匹配**
- 蛇形走线均匀分布，避免集中调谐
- 蛇形间距 ≥ 3倍线宽，减少串扰
- 长度匹配在接收端附近完成
- 同组信号的调谐模式保持一致

## 三、高速信号完整性 / 电源完整性 / EMC

### 3.1 约束驱动设计方法论

高速 PCB 设计采用约束驱动（Constraint-Driven）方法学：

**设计前定义三大类约束：**

1. **电气约束（Electrical Constraints）**
   - 阻抗要求（单端/差分）
   - 信号延迟与时序裕量
   - 串扰限制
   - 电压容差与纹波要求

2. **物理约束（Physical Constraints）**
   - 线宽、线间距
   - 过孔大小与间距
   - 差分对间距
   - 长度与长度匹配要求

3. **制造约束（Manufacturing Constraints）**
   - 最小线宽/间距（工艺能力）
   - 最小过孔尺寸
   - 铜厚与板材选择
   - 表面处理工艺

**四大设计目标：**
1. **SI（Signal Integrity）** - 信号完整性：确保信号质量
2. **PI（Power Integrity）** - 电源完整性：确保电源配送质量
3. **EMC（Electromagnetic Compatibility）** - 电磁兼容性：控制电磁辐射与抗扰度
4. **DFM（Design for Manufacturing）** - 可制造性：确保可批量生产

> **重要定义**：高速设计由信号的边沿速率（edge rate）决定，而非时钟频率。即使时钟频率不高，只要上升沿足够陡，就需要按高速设计处理。

### 3.2 信号完整性（SI）

**常见 SI 问题**
- 反射（Reflection）：阻抗不连续导致
- 串扰（Crosstalk）：相邻信号耦合
- 衰减（Attenuation）：介质与导体损耗
- 抖动（Jitter）：时序不确定性
- 眼图闭合：综合 SI 问题的表现

**SI 设计要点**
- 传输线阻抗控制（50Ω 单端 / 85-100Ω 差分）
- 终端匹配策略（源端匹配、端接匹配、AC耦合）
- 过孔阻抗优化（反焊盘优化、返回过孔）
- 串扰控制（间距、屏蔽、布线层选择）
- 损耗补偿（加重、均衡）

### 3.3 电源完整性（PI）

**PDN 设计目标**
- 在整个工作频率范围内，电源分配网络（PDN）的阻抗低于目标阻抗
- 目标阻抗 Z_target = V_ripple / I_transient

**PDN 设计方法**
- 电源层与地层紧密耦合，形成平板电容
- 合理配置去耦电容（容值梯度分布）
- BGA 下方放置近场去耦电容
- 电源入口处放置大容量滤波电容
- VRD（电压调整模块）输出电容优化

**去耦电容配置原则**
- 按容值从大到小分层配置：大容量电解 → 陶瓷电容 → 高频小电容
- 每个电源引脚都有对应的去耦路径
- 去耦电容过孔短而粗，降低寄生电感
- BGA 器件在背面对应引脚位置放置去耦电容

### 3.4 EMC 设计

#### 3.4.1 基础 EMC 规则

**完整地平面原则**
- 保持地平面的完整性，避免地平面被分割
- 高速信号下方必须有完整的参考平面
- 信号跨分割会导致回流路径不连续，严重恶化EMC
- 如必须分割，使用桥接电容或选层布线

**I/O 滤波**
- 所有 I/O 线路上添加铁氧体磁珠或 LC 滤波
- 接口处的共模电感抑制共模噪声
- ESD 防护器件靠近接口放置
- I/O 地与系统地通过电容或磁珠连接

**时钟与振荡器防护**
- 时钟电路下方保持完整地平面
- 振荡器下方不布信号线
- 时钟走线尽可能短，远离板边与接口
- 时钟输出添加串联阻尼电阻（协议允许时）

#### 3.4.2 防护环与板边缝合（2026 新增）

**防护环（Guard Rings）**
- 在时钟振荡器、高速 PLL 等强辐射源周围放置接地防护环
- 防护环由顶层和底层的接地铜皮 + 密集过孔连接构成
- 防护环宽度 ≥ 20mil，过孔间距 ≤ 100mil
- 防护环与内部电路之间保持足够间距，减少耦合

**板边缝合过孔（Edge Stitching Vias）**
- 沿 PCB 板边放置密集的接地缝合过孔
- 过孔间距 < 最高工作频率波长的 1/20（λ/20 规则）
- 缝合过孔连接顶层与底层的接地铜皮
- 形成类似法拉第笼的结构，抑制边缘辐射
- 同时增强板级 ESD 防护能力

**高速过孔附近的地过孔**
- 每个高速信号过孔旁都放置返回地过孔
- 返回过孔距离信号过孔 ≤ 3倍过孔间距
- 为返回电流提供最低阻抗路径
- 多层换层时，每层都应有对应的返回路径

### 3.5 电源入口去耦

**每个电源入口点的去耦配置：**
- 大容量电解电容或钽电容：滤除低频纹波
- 中容量陶瓷电容（1-10μF）：滤除中频噪声
- 高频小电容（0.1μF、0.01μF）：滤除高频噪声
- 磁珠或电感：隔离不同电源域的噪声
- TVS 或 ESD 器件：浪涌与静电防护

## 四、DFM / DFT / DFA 设计

### 4.1 DFM（可制造性设计）

**DFM 核心问题：电路板能否被制造出来？**

**DFM 检查要点：**

| 检查项目 | 检查内容 | 常见问题 |
|---------|---------|---------|
| 线宽/线间距 | 是否满足工厂最小工艺能力 | 线宽过细导致开路风险 |
| 层叠设计 | 铜厚、介质厚度、材料选择 | 阻抗不匹配、翘曲问题 |
| 过孔纵横比 | 孔径与板厚比例 | 一般 ≤ 1:8（常规工艺） |
| 焊环宽度 | 过孔焊盘与孔径差值 | 破环导致开路 |
| 铜平衡 | 上下层铜面积均衡 | 板翘曲变形 |
| 拼板设计 | 拼板方式、工艺边、定位孔 | 生产效率与成本 |
| 材料与表面处理 | 板材等级、表面处理工艺 | 可焊性、成本、可靠性 |

**DFM 通用规则**
- 线宽/线间距 ≥ 工厂最小工艺值 + 余量（建议留 20% 余量）
- 过孔焊环 ≥ 4mil（常规工艺）
- 板边到走线距离 ≥ 20mil
- 金属化孔到板边 ≥ 15mil
- 阻焊桥最小宽度 ≥ 4mil

### 4.2 DFT（可测试性设计）

**DFT 核心问题：电路板能否被测试？**

**DFT 两大核心思想：**
1. **可控性（Controllability）** - 能否通过测试输入将电路设置到特定状态
2. **可观测性（Observability）** - 能否通过测试输出观测到内部节点的状态

**DFT 检查要点：**

| 检查项目 | 检查内容 | 说明 |
|---------|---------|------|
| 关键网络测试点 | 电源、地、时钟、复位、关键信号 | 确保关键节点可测量 |
| 测试点几何尺寸 | 测试点大小、间距、间距要求 | 适配探针测试 |
| 治具间距 | 测试点与器件/板边间距 | 确保治具针床可达 |
| JTAG 链 | JTAG接口连接正确、链完整 | 边界扫描测试 |
| 飞针可达性 | 测试点是否可被飞针接触 | 小批量测试 |
| 功能测试接入 | 关键接口是否可外接测试设备 | 功能验证 |

**DFT 设计建议**
- 每个网络至少有一个测试点（关键网络必备）
- 测试点直径 ≥ 0.5mm，间距 ≥ 1.27mm（标准针床）
- 测试点均匀分布，避免局部过密
- JTAG 接口预留标准连接器
- 预留固件升级与调试接口

### 4.3 DFA（可装配性设计）

**DFA 核心问题：电路板能否高效、可靠地完成装配？**

**DFA 检查要点：**

| 检查项目 | 检查内容 | 说明 |
|---------|---------|------|
| 元件间距 | 元件之间、元件与板边间距 | 确保贴装与焊接质量 |
| 焊盘设计 | 焊盘尺寸、形状、间距 | 匹配元件封装与焊接工艺 |
| 极性标记 | 二极管、电解电容、IC等极性元件 | 明确的极性标识 |
| 散热焊盘 | 大功耗器件的散热焊盘设计 | 导热与焊接可靠性 |
| BGA 逃逸 | BGA 引脚扇出设计 | 确保所有引脚可引出 |
| 焊接可达性 | 焊盘是否可被焊锡良好润湿 | 避免阴影效应 |
| 检测可见性 | 焊点是否可被AOI/X-Ray检测 | 质量管控 |

**DFA 设计建议**
- 元件朝向统一，减少贴装旋转
- 同类元件间距 ≥ 0.5mm（0402及以上）
- 极性元件方向尽量一致（便于目检）
- 大元件周围留出返修空间
- 重元件（如大电解电容、变压器）靠近板边或支撑点
- 底部填充（underfill）元件的布局考虑

## 五、热设计

### 5.1 热设计基础

**热传递三种方式：**
- 热传导（Conduction）：通过固体介质传递
- 热对流（Convection）：通过流体（空气、液体）传递
- 热辐射（Radiation）：通过电磁波传递

**热设计目标：**
- 确保所有器件结温在额定范围内
- 避免热应力导致的可靠性问题
- 优化散热方案的成本与体积

### 5.2 PCB 热设计方法

**铜皮散热**
- 大面积接地铜皮帮助扩散热量
- 电源线宽增加以提升载流与导热能力
- 发热器件下方铺设散热铜皮
- 多层板通过过孔将热量传导至其他层

**散热过孔阵列（Thermal Vias）**
- 在裸露焊盘（Exposed Pad）器件下方布置密集散热过孔阵列
- 过孔将热量从顶层传导至底层或内层铜皮
- 过孔直径一般 0.2-0.5mm，间距 0.8-1.5mm
- 过孔数量根据功耗与散热需求确定
- 注意：过孔过多可能导致焊料流失（solder wicking）

### 5.3 重铜设计（2026 新增）

**重铜 PCB（Heavy Copper PCB）**
- 铜厚范围：2 oz 至 4 oz（甚至更高）
- 主要作用：横向热量分布，将局部热点扩散到更大面积
- 适用于大电流、高功耗应用场景
- 重铜层同时提升载流能力与导热能力

**重铜设计要点**
- 重铜层优先用于电源路径与散热路径
- 重铜层的线宽/间距需对应调整
- 重铜层与普通铜层的过渡设计
- 考虑重铜对层叠对称与翘曲的影响
- 成本随铜厚增加而上升，需权衡

### 5.4 DBC 基板（2026 新增）

**DBC（Direct Bond Copper）直接覆铜基板**
- 结构：陶瓷基板两面直接键合铜箔
- 陶瓷材料：Al₂O₃（氧化铝）、AlN（氮化铝）、Si₃N₄（氮化硅）
- 铜厚：通常 0.1-0.5mm
- 适用于高功率模块（IGBT、SiC MOSFET 模块）

**DBC 优势**
- 优异的绝缘性能
- 高热导率（AlN DBC 可达 170-230 W/m·K）
- 铜层载流能力强
- 热膨胀系数与半导体材料更匹配
- 可直接焊接功率器件

**应用场景**
- 电动汽车逆变器
- 工业变频器
- 光伏逆变器
- 大功率电源模块

### 5.5 SiC 器件热设计（2026 新增）

**SiC（碳化硅）器件热特性**
- 衬底热导率：120 ~ 170 W/m·K
- 结温可超过 175°C（部分器件可达 200°C+）
- 无需热降额（在额定结温范围内）
- 更高的工作温度允许更小的散热系统

**热阻参考值**

| 封装类型 | 热阻（结-壳） | 说明 |
|---------|-------------|------|
| TO-247 | ~0.2°C/W | 单管封装 |
| TO-220 | ~0.4°C/W | 单管封装 |
| 半桥模块 | ~0.05°C/W / 每开关位置 | 模块封装 |

**SiC 设计注意事项**
- 开关频率更高（可达 100kHz+），无源器件可小型化
- 更高的 dv/dt 与 di/dt 加剧 EMI 问题
- 驱动电路设计需考虑更高的开关速度
- 绝缘设计需适应更高的工作温度
- 焊料与封装材料需匹配高温工作条件

### 5.6 GaN 器件热设计（2026 新增）

**GaN（氮化镓）器件热特性**
- 热量集中在非常小的芯片面积上，形成局部热点
- 热流密度极高，热扩散挑战大
- 热设计的关键是将小面积的热量有效扩散出去
- 底部散热（bottom-side cooling）封装效果更好

**GaN 热设计要点**
- 尽量缩短从结到散热片的热路径
- 使用多个散热过孔，靠近器件热源
- 考虑使用 DBC 或IMS（绝缘金属基板）
- PCB 铜厚增加以利于热扩散
- 必要时使用底部散热封装与热界面材料

### 5.7 热设计检查清单

- [ ] 所有器件结温在额定范围内（含最坏情况）
- [ ] 发热器件均匀分布，避免局部热点
- [ ] 热敏感器件远离热源
- [ ] 散热路径清晰，热阻最低化
- [ ] 散热过孔阵列设计合理
- [ ] 电源路径铜厚/线宽满足载流与散热要求
- [ ] 考虑环境温度与海拔的影响
- [ ] 热仿真验证（复杂设计）

## 六、DDR5 / PCIe 布局规范

### 6.1 DDR5 布局要点

**DDR5 5600 阻抗要求**
- 地址/命令/控制信号：Z₀ = 50Ω（单端）
- 数据选通信号（DQS）：Z_diff = 80-100Ω（典型 85Ω）

**拓扑结构**
- **Fly-by 拓扑**：时钟、地址、命令信号沿一条主线路径依次到达每个DRAM
  - 优点：布线简单，信号完整性好
  - 缺点：到达每个DRAM的延迟不同，需读写训练补偿
  - 适用：DDR4/DDR5 标准设计

- **T 型分支（T-branch）拓扑**：信号在中间点分两路到达两组DRAM
  - 优点：两组延迟对称
  - 缺点：分支处阻抗不连续，易产生反射
  - 适用：对称布局的双Rank设计

**DDR5 布局规则**
- 数据通道按字节通道（byte lane）分组布线
- 同字节通道内信号长度匹配
- DQS 与对应 DQ 信号紧密耦合
- 地址/命令/控制信号与时钟长度匹配
- VDD/VSS 去耦电容靠近每个 DRAM 电源引脚
- 参考平面完整，避免高速信号跨分割
- 过孔数量最小化，关键信号尽量同层布线
- DDR5 依赖 MR（Mode Register）训练与 write/read deskew，布局需保证 byte-lane 分组、DQS-DQ 等长，便于训练收敛（2026 更新）

### 6.2 PCIe 布局规范

**PCIe 基本要求**
- 差分阻抗：85Ω ±10%
- 对内 skew：< 5mil（或按具体规格）
- AC 耦合电容：标准值 100nF（0.1μF）

#### PCIe 5XW / 4XRPH 规则（2026 新增）

**参考平面边缘间距（5XW 规则）**
- 高速差分信号距离参考平面边缘 ≥ 5倍线宽（5XW）
- 或 ≥ 5倍参考平面高度（5XRPH），取两者中较大值
- 原因：靠近平面边缘会导致阻抗不连续与辐射增加
- 板边、开槽、镂空处均需遵守此规则

**参考平面空洞间距（4XRPH 规则）**
- 高速差分信号距离参考平面中的空洞 ≥ 4倍参考平面高度（4XRPH）
- 空洞包括：过孔反焊盘过大形成的空隙、电源地平面的开槽等
- 空洞会中断回流路径，导致阻抗突变与信号质量下降

**PCIe 布局其他要点**
- 差分对优先布在顶层或底层，紧邻完整地平面
- 避免高速差分信号换层（如需换层必须添加返回地过孔）
- AC 耦合电容靠近发送端放置（或按器件规格要求）
- 差分对走线远离板边（至少 3W，高速设计按 5XW 规则）
- RX 与 TX 通道之间保持足够间距，减少串扰
- 时钟信号与高速通道保持距离

#### PCIe 5.0 应用要点（2026 更新）

PCIe 5.0 信号速率提升到 **32 GT/s**，对布线与板材提出更高要求：

- 奈奎斯特频率约 16 GHz，通道损耗预算紧张（单向通道损耗预算典型 <20dB @16GHz，需经 SI 仿真核算）
- 优先采用低损耗高频板材（Megtron6 类，Dk≈3.2-3.5、Df 更低），FR4 高速档仅适用于短距离互连
- 高速过孔必须背钻清除 stub，返回地过孔密度与位置需经 SI 仿真验证
- 眼图裕量与抖动预算需结合过孔、连接器、封装模型进行完整 SI 仿真
- 差分阻抗仍为 85Ω±10%，5XW / 4XRPH 规则在 32 GT/s 下为强制约束

## 七、AI 硬件可靠性设计要点（2026 新增）

面向 AI 加速卡、AI 服务器等高密度计算硬件的 12 条可靠性设计规则：

1. **电源冗余设计** - 关键电源路径支持 N+1 冗余
2. **热裕量充足** - 所有器件结温保留至少 20% 裕量
3. **去帽可靠性** - 每类电容评估去帽后的系统影响
4. **时序裕量** - 高速接口时序裕量 > 20% UI
5. **降额设计** - 电压、电流、温度均按降额规范设计
6. **EMC 裕量** - 辐射与抗扰测试保留 6dB 以上裕量
7. **连接器降额** - 连接器电流/电压降额 50% 以上
8. **PCB 材料等级** - 高可靠应用使用 High-Tg、低损耗材料
9. **测试覆盖** - 关键故障模式的测试覆盖率 > 95%
10. **寿命预测** - 基于加速老化模型预测产品寿命
11. **FMEA 分析** - 系统化的失效模式与影响分析
12. **热仿真验证** - 全板级热仿真验证最坏工况
