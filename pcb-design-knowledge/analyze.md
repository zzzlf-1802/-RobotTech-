# PCB 设计分析理论基础

> 本文档汇总 PCB 设计相关的理论基础知识，包括电路理论、电磁学、控制理论、数学工具、热分析、可靠性分析等，为设计实践提供理论支撑。

---

## 一、电路理论

### 1.1 基本定律

**基尔霍夫定律**
- **KCL（基尔霍夫电流定律）**：任一节点，流入电流之和等于流出电流之和（ΣI_in = ΣI_out）
- **KVL（基尔霍夫电压定律）**：任一闭合回路，电压代数和为零（ΣV = 0）

**欧姆定律**
- 直流：V = I × R
- 交流（频域）：V = I × Z，其中 Z 为复阻抗

**戴维南定理**
- 任何线性含源一端口网络，对外电路而言可等效为一个电压源与一个电阻的串联
- 电压源电压 = 端口开路电压
- 串联电阻 = 网络内所有独立源置零后的端口等效电阻

**诺顿定理**
- 任何线性含源一端口网络，对外电路而言可等效为一个电流源与一个电阻的并联
- 电流源电流 = 端口短路电流
- 并联电阻 = 戴维南等效电阻

### 1.2 交流电路分析

**阻抗与导纳**
- 电阻阻抗：Z_R = R
- 电感阻抗：Z_L = jωL = j2πfL
- 电容阻抗：Z_C = 1/(jωC) = -j/(ωC)
- 导纳：Y = 1/Z = G + jB（电导 + 电纳）

**RLC 串联谐振**
- 谐振频率：f₀ = 1/(2π√(LC))
- 品质因数：Q = ω₀L/R = 1/(ω₀CR)
- 谐振时阻抗最小（Z = R），电流最大

**RLC 并联谐振**
- 谐振频率：f₀ = 1/(2π√(LC))（高 Q 时近似）
- 谐振时阻抗最大，电流最小

### 1.3 传输线理论

**传输线特征阻抗**
- 微带线：Z₀ ≈ (87/√(ε_r + 1.41)) × ln(5.98h/(0.8w + t))
- 带状线：Z₀ ≈ (60/√ε_r) × ln(4b/(0.67πw(0.8 + t/w)))
- 其中：w = 线宽，h = 介质厚度，t = 铜厚，ε_r = 介电常数，b = 两参考平面间距

**信号传播速度**
- v = c / √ε_eff
- c = 光速（3×10⁸ m/s）
- ε_eff = 有效介电常数（微带线介于 1 和 ε_r 之间）

**反射系数**
- Γ = (Z_L - Z₀) / (Z_L + Z₀)
- Z_L = 负载阻抗，Z₀ = 传输线特征阻抗
- |Γ| = 0 表示完全匹配，|Γ| = 1 表示全反射

**驻波比（VSWR）**
- VSWR = (1 + |Γ|) / (1 - |Γ|)
- 完全匹配时 VSWR = 1，全反射时 VSWR = ∞

## 二、电磁学基础

### 2.1 麦克斯韦方程组

**积分形式**

| 定律 | 积分方程 | 物理意义 |
|-----|---------|---------|
| 法拉第电磁感应 | ∮E·dl = -dΦ_B/dt | 变化的磁场产生电场 |
| 安培环路定理 | ∮H·dl = I + dΦ_D/dt | 电流和变化的电场产生磁场 |
| 高斯定理（电场） | ∮D·dS = Q | 电场通量等于闭合面内电荷 |
| 高斯定理（磁场） | ∮B·dS = 0 | 磁场是无源场（无磁单极） |

**各量关系**
- D = εE（电位移矢量 = 介电常数 × 电场强度）
- B = μH（磁感应强度 = 磁导率 × 磁场强度）
- J = σE（电流密度 = 电导率 × 电场强度）

### 2.2 电磁波基础

**平面电磁波**
- 在理想介质中，电场与磁场相互垂直，且都垂直于传播方向（横电磁波 TEM）
- 波阻抗：η = E/H = √(μ/ε)
- 自由空间波阻抗：η₀ ≈ 377Ω
- 传播速度：v = 1/√(με)

**趋肤效应（Skin Effect）**
- 高频电流集中在导体表面薄层
- 趋肤深度：δ = √(2/(ωμσ)) = 1/√(πfμσ)
- 铜的趋肤深度（20°C）：δ ≈ 66/√f (mm)
- 影响：高频下导线有效截面积减小，电阻增大

**邻近效应（Proximity Effect）**
- 相邻导线的电流相互影响，导致电流分布不均匀
- 高频差分对中电流集中在两线相对的内侧
- 进一步增加交流电阻

### 2.3 EMC 相关理论

**辐射产生机理**
- 差模辐射：由信号回路电流产生，通常较小
- 共模辐射：由电缆等结构上的共模电流产生，通常是主要辐射源
- 共模辐射公式：E ≈ 1.26 × I_cm × L × f / r（远场近似）

**辐射抑制方法**
- 减小回路面积（差模）
- 减小共模电流（共模）
- 屏蔽与滤波
- 接地与搭接

**串扰机理**
- 容性串扰（电场耦合）：dV/dt 通过互电容耦合
- 感性串扰（磁场耦合）：di/dt 通过互电感耦合
- 远端串扰 = 容性串扰 - 感性串扰
- 近端串扰 = (容性串扰 + 感性串扰) / 2

## 三、控制理论基础

### 3.1 反馈控制基础

**闭环控制系统组成**
- 参考输入 R(s)
- 比较环节：误差 E(s) = R(s) - H(s)C(s)
- 控制器 G_c(s)
- 被控对象 G_p(s)
- 输出 C(s)
- 反馈环节 H(s)

**传递函数**
- 前向通道传递函数：G(s) = G_c(s) × G_p(s)
- 闭环传递函数：T(s) = G(s) / (1 + G(s)H(s))
- 误差传递函数：E(s)/R(s) = 1 / (1 + G(s)H(s))

### 3.2 稳定性分析

**劳斯-赫尔维茨判据**
- 根据特征方程系数判断系统稳定性
- 劳斯阵列第一列元素全为正则系统稳定

**奈奎斯特判据**
- 根据开环频率响应判断闭环稳定性
- 观察奈奎斯特图绕 (-1, j0) 点的圈数

**稳定裕度**
- 相位裕度（PM）：增益为 0dB 时，相位距 -180° 的余量
- 增益裕度（GM）：相位为 -180° 时，增益距 0dB 的余量
- 一般要求：PM ≥ 45°，GM ≥ 6dB

### 3.3 电源控制环路

**开关电源控制模式**
- 电压模式控制：单环控制，仅反馈输出电压
- 电流模式控制：双环控制，内环电流环 + 外环电压环
- 峰值电流模式、平均电流模式

**补偿网络设计**
- Type I：单极点补偿（单积分）
- Type II：极点-零点补偿（积分 + 单极点）
- Type III：双极点-双零点补偿（积分 + 双极点双零点）
- 根据功率级传递函数选择合适补偿类型

## 四、数学工具

### 4.1 复频域分析

**拉普拉斯变换**
- 定义：F(s) = ∫₀^∞ f(t)e^(-st)dt
- s = σ + jω（复频率）
- 常用变换对：
  - 单位阶跃：u(t) ↔ 1/s
  - 指数：e^(-at)u(t) ↔ 1/(s+a)
  - 正弦：sin(ωt)u(t) ↔ ω/(s²+ω²)
  - 微分：df/dt ↔ sF(s) - f(0⁻)

**傅里叶变换**
- 定义：F(jω) = ∫_{-∞}^∞ f(t)e^(-jωt)dt
- 拉普拉斯变换在 s = jω 轴上的特例
- 用于稳态频域分析

### 4.2 信号完整性常用数学

**上升时间与带宽关系**
- 估算公式：BW ≈ 0.35 / t_r
- t_r = 10%-90% 上升时间
- 适用于单极点系统近似

**传输线延迟**
- 延迟时间：t_pd = √(ε_eff) / c × l
- c = 光速，l = 线长
- FR4 材料：约 150-180 ps/in（约 6-7 ps/mm）

**衰减计算**
- 导体损耗：α_c ∝ √f（趋肤效应）
- 介质损耗：α_d ∝ f（介质极化损耗）
- 总损耗：α_total = α_c + α_d（单位：dB/m 或 Np/m）

### 4.3 统计分析

**正态分布**
- 概率密度函数：f(x) = (1/(σ√(2π))) × e^(-(x-μ)²/(2σ²))
- μ = 均值，σ = 标准差
- 68-95-99.7 法则：±1σ/±2σ/±3σ 区间概率

**六西格玛（Six Sigma）**
- 设计目标：过程能力 Cpk ≥ 1.33（4σ）或 ≥ 1.67（5σ）
- 阻抗控制、尺寸公差等指标常参考此标准

## 五、热分析理论

### 5.1 热传导基本定律

**傅里叶热传导定律**
- q = -k × dT/dx
- q = 热流密度（W/m²）
- k = 热导率（W/m·K）
- dT/dx = 温度梯度

**热阻概念**
- 热阻 R_θ = ΔT / P（°C/W 或 K/W）
- 类比电路中的电阻
- 热流类比电流，温差类比电压

**热阻串联**
- R_total = R₁ + R₂ + R₃ + ...
- 例：结-壳-散热器-环境 各段热阻串联

### 5.2 常用材料热导率（2026 扩充）

| 材料 | 热导率（W/m·K） | 备注 |
|-----|---------------|------|
| 铜（纯铜） | 401 | PCB 铜箔 |
| 铝 | 205 | 散热器常用 |
| 金 | 315 | 键合线等 |
| 银 | 429 | 最高的金属之一 |
| FR4（横向） | 0.3-0.5 | PCB 基板材料 |
| FR4（纵向） | 0.8-1.2 | 含铜过孔增强 |
| 氧化铝陶瓷（Al₂O₃） | 20-35 | DBC 基板 |
| 氮化铝陶瓷（AlN） | 170-230 | 高导热 DBC |
| 氮化硅陶瓷（Si₃N₄） | 20-90 | 高韧性 DBC |
| **SiC 衬底** | **120-170** | **2026 新增** |
| 硅（Si） | 150 | 传统硅基器件 |
| GaN（GaN-on-Si） | 130-200 | 取决于衬底 |
| 空气 | 0.026 | 自然对流介质 |
| 导热硅脂 | 0.5-5 | 热界面材料 |
| 导热垫 | 1-10 | 热界面材料 |

### 5.3 DBC 基板热特性（2026 新增）

**DBC（Direct Bond Copper）直接覆铜基板热阻**

| DBC 类型 | 陶瓷厚度 | 铜厚 | 典型热阻（cm²·K/W） | 适用场景 |
|---------|---------|------|-------------------|---------|
| Al₂O₃ DBC | 0.38mm | 0.3mm | ~0.3-0.5 | 中功率模块 |
| Al₂O₃ DBC | 0.63mm | 0.3mm | ~0.5-0.7 | 高绝缘中功率 |
| AlN DBC | 0.38mm | 0.3mm | ~0.1-0.2 | 高功率模块 |
| AlN DBC | 0.63mm | 0.3mm | ~0.15-0.25 | 高绝缘高功率 |
| Si₃N₄ DBC | 0.32mm | 0.3mm | ~0.15-0.3 | 高可靠性功率 |

**DBC 热设计要点**
- 铜层越厚，横向热扩散越好，热阻越低
- 陶瓷层越薄，纵向热阻越小，但绝缘耐压降低
- 芯片贴装区域的热流密度最高，是热设计瓶颈
- 多个功率芯片在 DBC 上的布局影响热分布

### 5.4 散热计算方法

**自然对流散热估算**
- 散热面积 A（m²）
- 温升 ΔT（°C）
- 自然对流换热系数 h ≈ 5-10 W/m²·K（垂直平板）
- 散热量 P = h × A × ΔT

**强制对流散热**
- 换热系数 h 随风速增加而增大
- 风速 1m/s：h ≈ 20-30 W/m²·K
- 风速 5m/s：h ≈ 50-100 W/m²·K

**热仿真方法**
- 有限元法（FEM）：ANSYS Icepak、FloTHERM 等
- 计算流体动力学（CFD）：考虑流体流动与热交换
- 简化模型：热阻网络模型（用于快速估算）

## 六、可靠性分析

### 6.1 可靠性基本概念

**可靠性（Reliability）**
- 定义：产品在规定条件下和规定时间内完成规定功能的概率
- 表示：R(t) = P(T > t)，T 为失效时间

**失效率（Failure Rate）**
- 瞬时失效率：λ(t) = f(t)/R(t)
- 单位：FIT（Failure In Time），1 FIT = 10⁻⁹/h
- 或用 %/1000h 表示

**平均无故障时间（MTBF）**
- MTBF = 1/λ（恒定失效率时）
- 单位：小时（h）
- 注意：MTBF 不是产品的预期寿命

**任务可靠性（Mission Reliability）**
- 在特定任务时间内不失效的概率
- R(t_mission) = e^(-t_mission / MTBF)（指数分布）

**可靠性指标关系表**

| 指标 | 符号 | 单位 | 含义 |
|-----|------|------|------|
| 可靠度 | R(t) | 无量纲（概率） | t 时刻仍正常工作的概率 |
| 平均无故障时间 | MTBF | 小时 | 两次失效间的平均时间 |
| 失效率 | λ(t) | FIT 或 %/1000h | 单位时间内失效的概率 |
| 任务可靠度 | R(t_mission) | 无量纲 | 任务期间不失效的概率 |

### 6.2 常用可靠性标准（2026 扩充）

**国际/军用标准**

| 标准编号 | 标准名称 | 适用范围 |
|---------|---------|---------|
| MIL-HDBK-217F | 电子设备可靠性预测 | 美军标，Parts Count / Parts Stress 法 |
| Telcordia SR-332 | 电子设备可靠性预测 | 贝尔通信标准，3 Parts Count / Parts Stress |
| IEC 61709 | 电子元器件可靠性 | 国际电工委员会标准 |
| **GJB 450A** | **装备可靠性工作通用要求** | **中国军用标准（2026 新增）** |
| **GJB 9001C** | **质量管理体系要求** | **中国军用质量标准（2026 新增）** |
| GJB/Z 299 | 电子设备可靠性预计手册 | 中国军用可靠性预计 |

**MTBF 预测方法**
- **Parts Count 法（零件计数法）**：
  - 基于元器件数量与类型的粗略估算
  - 适用于设计早期，信息不足时
  - Telcordia 3 Parts Count 方法

- **Parts Stress 法（零件应力法）**：
  - 考虑电气应力和热应力的详细计算
  - 适用于详细设计阶段
  - 需要各器件的工作参数与环境参数
  - MIL-217-F2 Parts Stress 方法

### 6.3 失效分布模型

**指数分布**
- 失效率恒定：λ(t) = λ
- 可靠度：R(t) = e^(-λt)
- MTBF = 1/λ
- 适用于电子产品偶然失效期（浴盆曲线中间段）

**威布尔分布（Weibull Distribution）**（2026 新增）
- 可靠度函数：R(t) = e^(-(t/η)^β)
- β = 形状参数，η = 特征寿命（尺度参数）
- β < 1：早期失效期（失效率递减）
- β = 1：偶然失效期（指数分布，失效率恒定）
- β > 1：耗损失效期（失效率递增）
- 适用：描述全生命周期的失效规律

**浴盆曲线**
- 早期失效期：失效率递减，由制造缺陷引起
- 偶然失效期：失效率近似恒定，随机失效
- 耗损失效期：失效率递增，老化磨损引起

### 6.4 EOS（Electrical Over-Stress）电过应力（2026 新增）

**EOS 定义**
- 电气过应力：器件承受的电压或电流超过其额定值
- 导致器件性能退化或永久失效
- 是电子器件失效的主要原因之一

**EOS 与 ESD 的区别**

| 特性 | EOS | ESD |
|-----|-----|-----|
| 持续时间 | 较长（微秒到毫秒级） | 很短（纳秒级） |
| 能量 | 能量较大 | 能量相对较小但功率极高 |
| 电压范围 | 几伏到几百伏 | 几百伏到几万伏 |
| 典型原因 | 电源过压、误操作、短路 | 静电放电、人体模型 |
| 失效模式 | 过热烧毁、金属熔融 | 栅氧击穿、结损伤 |

**EOS 常见来源**
- 电源浪涌与过压
- 热插拔操作
- 测试过程中的误操作
- 电源时序问题
- 短路或过载

**EOS 防护设计**
- 过压保护（TVS、齐纳二极管）
- 过流保护（保险丝、限流电路）
- 电源时序控制
- 热插拔缓启动
- 输入电压钳位
- EOS 违规检测（自动化工具可检测设计中的 EOS 风险）

### 6.5 FMEA 失效模式与影响分析

**FMEA 基本概念**
- 系统化分析产品所有可能的失效模式
- 评估每种失效的影响与风险
- 识别高风险项并采取改进措施

**FMEA 评分体系**
- S（Severity）严重度：失效影响的严重程度（1-10分）
- O（Occurrence）发生度：失效发生的概率（1-10分）
- D（Detection）探测度：失效被发现的难易程度（1-10分）
- RPN（Risk Priority Number）风险优先级数 = S × O × D

**自动化 FMEA 工具（2026 新增）**
- Synthelyzer ECAD 插件：从 ECAD 设计自动生成 FMEA
- 自动识别失效模式与影响
- 减少人工分析工作量
- 提高分析一致性与完整性

### 6.6 降额设计

**降额设计原则**
- 器件在低于其额定值的条件下工作
- 提高可靠性，延长使用寿命
- 不同器件降额系数不同

**常用降额系数参考**

| 器件类型 | 电压降额 | 电流降额 | 温度降额 |
|---------|---------|---------|---------|
| 电阻器 | 50-70% | 50-70% | - |
| 电容器 | 50-80% | - | 降低10-20°C |
| 二极管 | 70-80% | 50-70% | 降低10-20°C |
| MOSFET | 70-80% | 50-70% | 降低20°C以上 |
| IC | 80-90% | - | 降低10-15°C |
